RAM PARTITION (32KB):
]     0,   0xFF[ <- ZERO PAGE                       256   BYTES
] 0x100, 0x6000[ <- OS                ( 75% OF RAM) 24576 BYTES
]0x6001, 0x8000[ <- PROGRAM'S STORAGE (~25% OF RAM) 7936  BYTES



ZERO PAGE:
FAST ACCESS RAM PAGE
- FIRST 3 BYTES CONTAIN JMP TO OS START DIRECTION (BYTE-256)
- STACK (BYTE-3, BYTE 254) (42NT SUBRUTINE ANIDATION LEVEL)
- BYTE-255 TIENE LA INSTRUCCION QUE ESTABLECE EL STACK POINTER EN 2 (NO EN 3)

OS:
FIRST INSTRUCTIONS AND AFTER PROGRAM DATA
- DRIVERS
- TOOLS (LIST'S, MATH, TIMERS, CONTROL ETC..)
- TABLES (HEXADECIMAL, ASCII(PERSONALIZED) )
- DINAMYC MEMORY BLOCKS (SHARED BY ALL PROGRAMS)
- OS & SYSTEM CONSTANT VARIABLES (EX: BYTES OF RAM, CPU HZ, ETC..)
- ETC..

PROGRAM'S STORAGE:
- PROGRAM INSTRUCTIONS AND DATA (DATA AT THE END)
